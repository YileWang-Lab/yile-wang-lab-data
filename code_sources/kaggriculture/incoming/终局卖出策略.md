# Kaggriculture 终局清算与量化逼空策略白皮书 (V4.0 终极博弈版)

本策略文档建立在严格的运筹学与非合作博弈（Non‑cooperative Game Theory）框架之上。在游戏进入禁止任何长期投资（`BUY_SEED`, `BUY_ANIMAL`）的死线阶段后，本策略将指导 Agent 完成**自身资产的物理极限变现**，并针对处于纳什均衡下的完美理性对手，实施**绝对无风险的量化逼空（Short Squeeze）** 与**先发制人的市场抢跑（Market Front‑running）**。

## I. 博弈论前提与核心参数定义

在终局阶段，双方的决策空间坍缩。定义当前环境与状态参数如下：

* $T_{total}=720$：游戏总回合数。
* $R = T_{total} - T_{current}$：剩余回合数。
* $D = \lfloor R/24 \rfloor$：剩余游戏天数（决定动物消耗与产出次数）。
* $A, W, F, M$：分别代表动物数量、工人数（手部动作上限）、小麦库存、现金（下标 $me$ 表示我方，$opp$ 表示对手）。
* $P(I)$：小麦动态价格函数，随市场库存 $I$ 严格单调递减，值域区间约为 $[1,45]$。其精确分段定义见官方 `MARKET_PARAMS`。
* $P_{sell}(I)$：产物（如牛奶）卖出价格函数，随市场库存 $I$ 增加而严格单调递减。

**完美理性假设**：对手的 Agent 将严格按照最大化最终现金 $M_{final}$ 的目标执行决策。当且仅当某项操作的边际净收益 $\Delta U > 0$ 时，对手才会执行该操作。

## III. 自身资产的最优清算模型 (Optimal Liquidation)

在终局，继续保留活体动物的唯一目的是压榨其产物。清算的核心约束为**手部动作容量（Action Economy）**。

### 1. 清算倒计时方程

设我方拥有同质化动物 $A_{me}$，工人数 $W_{me}$。每次 `PICKUP` 消耗 1 个 Hand 动作。将所有动物打包进背包所需的绝对最小回合数为：

$$R_{pack} = \left\lceil \frac{A_{me}}{W_{me}} \right\rceil$$

由于 `SELL` 指令可在一回合内无限量合并打包，完整的清仓物理极限界限为：

$$R_{clear} = \left\lceil \frac{A_{me}}{W_{me}} \right\rceil + 1$$

### 2. 利润最大化执行流

* **常规榨取期 ($R > R_{clear}$)**：正常执行 `FEED`、`PICKUP Product` 和 `SELL Product`。**绝不执行 `PICKUP Animal`**。
* **极限回收期 ($R \le R_{clear}$ 开始)**：停止所有农事活动，全员执行 `PICKUP Animal`。
* **终局抛售期 ($R = 1$，即 Step 719)**：
  * 执行合并出售：`["SELL", "ANIMAL_NAME", A_{me}]`。
  * 清理所有剩余库存（化肥、种子、多余产物）。

**化肥清算特判**：若持有化肥且有未成熟作物，当且仅当 $\Delta Q \cdot P_{crop} > P_{fert\_sell}$ 时执行 `FERTILIZE`，否则在最后一步直接抛售化肥本身。

## IV. 零和博弈下的市场抢跑战术 (Market Front‑running Protocol)

当双方都养殖了同类动物（如奶牛）或种植了同类高端作物（如西瓜）时，终局的产物抛售是一场残酷的**零和流动性争夺战**。

### 1. 滑点暴跌的数学证明

设当前市场产物（如 MILK）库存为 $I_0$。我方持有 $Q_m$ 瓶牛奶，对手持有 $Q_o$ 瓶牛奶。因抛售会导致库存 $I$ 增加，卖出价格 $P_{sell}(I)$ 严格单调递减。

* **抢跑者（先卖出）的总收益**：
  $$U_{front} = \sum_{k=1}^{Q_m} P_{sell}(I_0 + k)$$

* **接盘者（后卖出）的总收益**（此时市场已被砸盘，库存起点变为 $I_0 + Q_o$）：
  $$U_{lag} = \sum_{k=1}^{Q_m} P_{sell}(I_0 + Q_o + k)$$

**定理**：由于 $P_{sell}(I)$ 严格递减且 $Q_o > 0$，因此 $U_{front} - U_{lag} \gg 0$ 严格成立。在高端产物（触发 `above_target` 暴跌机制）中，迟滞抛售将导致资产瞬间缩水至 $\$1$ 地板价。

### 2. T-1 精确截杀计算

完美理性的对手必然会计算其最优清算回合：
$$T_{opp\_clear} = 720 - \left( \left\lceil \frac{A_{opp}}{W_{opp}} \right\rceil + 1 \right)$$

为了实现无损抢跑且不影响我方产出，我方的抛售回合 $T_{dump}$ 必须设定为：
$$T_{dump} = \min\left( T_{me\_clear},\; T_{opp\_clear} - 1 \right)$$

**执行方案**：在 $T_{dump}$ 这一回合，在 `market` 数组的最优先位置（Index 0）强行下达 `["SELL", "MILK", Q_m]`，将市场库存瞬间填满，迫使对手在下一回合只能以 $\$1$ 的废纸价结算其一生心血。

## V. 量化逼空与对手囤粮的反制 (Squeeze & Counter‑Hoarding)

这是利用小麦（Wheat）市场 $P_{buy}(I)$ 随库存减少而飙升的特性，构建的套利陷阱。

### 1. 对手的绝对刚需与有效临界点

对手维持 $A_{opp}$ 头动物生存的小麦缺口为：
$$Q_o = \max\left(0,\; A_{opp} \cdot D - F_{opp}\right)$$

**重要修正**：需侦察对手未收获的小麦地块数量 $U_{wheat}$，若剩余回合足够其收获（$\lceil U_{wheat}/W_{opp} \rceil \le D\cdot 24$），则将 $F_{opp}$ 修正为 $F_{opp} + U_{wheat}$。

在产物价值远高于麦价的客观前提下，对手的有效资金承受极限（天花板）为：
$$P_{eff}^* = \min\left(45,\; \left\lfloor \frac{M_{opp}}{Q_o} \right\rfloor \right)$$

### 2. 套利不等式

我们在 $T-1$ 消耗市场库存买入 $Q_m$，对手在 $T$ 被迫买入 $Q_o$，我们在 $T+1$ 抛售 $Q_m$。我方净利润 $\Pi$ 为：

$$\Pi = \sum_{i=1}^{Q_m} P\bigl(I_{start} - Q_o - i + 1\bigr) - \sum_{i=1}^{Q_m} P\bigl(I_{start} - i + 1\bigr)$$

**证明**：由于 $P(I)$ 严格单调递减且 $Q_o > 0$，对于任意 $i$ 有 $P(I_{start}-Q_o-i+1) > P(I_{start}-i+1)$，因此 $\Pi > 0$ 严格成立。且因 AMM 曲线的非线性，$Q_m$ 越大，$\Pi$ 的增长呈超线性。

**定理**：只要满足 $Q_o > 0$ 且拉盘后价格 $P_{spike} \le P_{eff}^*$，逼空套利利润严格为正，且 $Q_m$ 越大，利润越高。

### 3. 最优买入量的确定

设我方可用资金 $B = M_{me} - 500$（保留安全垫），当前市场库存 $I_{start}$。最优买入量 $Q_m^*$ 由以下条件决定：

1. **价格天花板约束**：$P(I_{start} - Q_m^*) < P_{eff}^*$
2. **资金约束**：$\sum_{i=1}^{Q_m^*} P(I_{start} - i + 1) \le B$

可通过二分法或贪心累加求解。**注意**：买入量不应受对手需求 $Q_o$ 限制，因为多买的部分在卖出时会因库存更低而获得更高均价，且中间部分相互抵消，利润仅取决于前 $Q_o$ 笔交易的价差。

### 4. 纳什反制：对手提前囤粮的博弈判定

**情境**：如果对手也是完美理性 AI，他会算出可能被逼空，从而在终局前（如 Step 600）提前花费资金买足小麦，使得 $F_{opp} \ge A_{opp} \cdot D$。

**数学解构与应对策略**：
当侦察到 $F_{opp} \ge A_{opp} \cdot D$ 时，意味着 $Q_o = 0$。逼空引擎的第一道安全锁将自动触发并**放弃逼空（Return 0）**。

此时，我们非但没有吃亏，反而获得了**流动性优势（Liquidity Advantage）**：
1. **资金的机会成本陷阱**：对手为了防守，提前锁死了大量现金（囤积了数百个小麦）。这意味着他在 Step 600‑700 期间的资金利用率为 $0$，无法利用这笔钱购买化肥或应对突发市场波动。
2. **战略枢纽切换（Pivot）**：对手成功保住了动物，意味着他必然会在最后几回合产生海量的动物产物。我方策略直接无缝切换至 **IV. 市场抢跑战术 (Front‑running)**，利用我们保存的充裕现金雇佣临时工（`HIRE`），以更快的手部动作将产物打包，并在 $T_{opp\_clear} - 1$ 实施毁灭性的砸盘截杀。

## VI. 终局综合战役指挥引擎 (Master Execution Engine)

将上述两大数学模块融合，形成终极 AI 的后处理（Post‑processing）裁决层。

```python
import math

def endgame_master_controller(obs, my_info, opp_info):
    """
    终局量化裁决引擎，负责接管游戏最后 50 步的战略调度
    """
    current_step = obs['step']
    days_left = math.floor((720 - current_step) / 24)

    # --- 模块 1：计算绝对死线 ---
    my_clear_round = 720 - (math.ceil(my_info['total_animals'] / my_info['workers']) + 1)
    opp_clear_round = 720 - (math.ceil(opp_info['total_animals'] / opp_info['workers']) + 1)

    actions = {'market': [], 'hands': []}

    # --- 模块 2：市场抢跑 (Front-running) 判定 ---
    if current_step == opp_clear_round - 1:
        for product in ['MILK', 'WOOL', 'EGG', 'MELON', 'STRAWBERRY']:
            qty = my_info['inventory'].get(product, 0)
            if qty > 0:
                actions['market'].insert(0, ["SELL", product, qty]) 

    # --- 模块 3：量化逼空 (Wheat Squeeze) 判定 ---
    # 修正对手小麦库存：考虑未收获作物
    effective_F_opp = opp_info['wheat_inventory'] + estimate_unharvested_wheat(obs, opp_info)
    Q_o = max(0, opp_info['total_animals'] * days_left - effective_F_opp)

    if Q_o > 0 and current_step < opp_clear_round - 1:
        p_eff_star = min(43, opp_info['money'] // Q_o)
        wheat_price = obs['market']['WHEAT']['price']
        budget = my_info['money'] - 500  # 安全保证金
        
        if wheat_price < p_eff_star and budget > 500:
            qty_to_buy = calculate_optimal_squeeze(budget, p_eff_star, obs['market']['WHEAT']['inventory'])
            if qty_to_buy > 0:
                actions['market'].append(["BUY_PRODUCT", "WHEAT", qty_to_buy])
                
    # --- 模块 4：自身清算 (Self Liquidation) 判定 ---
    if current_step >= my_clear_round:
        # 停止喂养，全力打包活体资产
        actions['hands'] = generate_pickup_actions(my_info['animals_in_field'], my_info['workers'])
        
        # 如果是游戏最后一步，一键变现所有库存
        if current_step == 719:
            actions['market'] = generate_final_dump(my_info['inventory'])
            
    return actions


### 辅助函数说明

- `estimate_unharvested_wheat(obs, opp_info)`：根据对手地块状态估算未收获小麦数量，并判断剩余回合是否足够收获。
- `calculate_optimal_squeeze(budget, p_eff_star, inventory)`：二分法或贪心计算满足资金与价格天花板约束的最大买入量。
- `generate_pickup_actions(animals_in_field, workers)`：生成 `PICKUP` 动作列表，每回合不超过 `workers` 个。
- `generate_final_dump(inventory)`：生成最终卖出所有库存的 `market` 动作。

## VII. 风险与边界条件总结

| 风险场景 | 数学结果 | 应对措施 |
|---------|---------|---------|
| 对手不买小麦 ($Q_o=0$) | $\Pi=0$，本金无损 | 自动放弃逼空，切换至抢跑 |
| 对手资金不足 | 无法接盘，$Q_o=0$ | 放弃逼空，避免资金占用 |
| 价格已达天花板 ($P\approx 45$) | 套利空间消失 | 停止买入，避免无效占用 |
| 对手提前囤粮 | $Q_o=0$，逼空失效 | 利用资金优势实施抢跑 |
| 引擎同回合结算 | 不等式仍成立，利润略减 | 无需额外操作 |
| 自身清算与逼空并行 | 互不冲突，可同时执行 | 确保资金安全垫 |

**最终结论**：本策略在数学上保证了**绝对无风险、保本不亏、上不封顶**的套利空间，同时兼顾了自身资产的物理极限变现。所有决策均可通过公开观测数据精确计算，无需任何主观风险系数。
