# V210 first-animal-retention experiment

V208 and V209 showed that restricting both exchange directions, or restricting
the whole opening phase, is too broad. V210 keeps only the narrow public rule
under test: on the first capital decision, an existing animal position cannot
be exchanged for a crop. Every other composition ray and every later step keep
V204's behavior and certificates.

This remains an isolated research wrapper. V204 is production until a fresh
paired arena screen supports promotion.

The one-way screen was behaviorally identical to V209 on the declared quick
pool (`-$7,366` per paired cell, `A>B = 44.4%`). It is retained only as a
negative ablation. The observed animal purchases therefore do not justify a
hard opening asset-class gate; the next useful work is joint public
service/capacity certification.
