# V209 first-capital asset-class experiment

V208's whole first-quadrant gate changed every capital replan before land
expansion and lost on the hard-pool screen. V209 isolates the hypothesis to
the first public capital decision only:

- at engine `step == 0`, the existing exchange may change animals only to
  animals and crops only to crops;
- all later steps use V204's original exchange set;
- the strict public cash, route, service and paid-response certificates remain
  the acceptance test.

This is a research wrapper; V204 remains production until a fresh paired
screen supports promotion. The runtime uses only current observation, public
engine step and engine asset classes.

The screen still rejected the rule: V209 fired in all 18 paired hard-pool
cells and averaged **-$7,366 per paired cell** (`A>B = 44.4%`). Limiting the
gate to the first public capital decision did not recover the loss.
