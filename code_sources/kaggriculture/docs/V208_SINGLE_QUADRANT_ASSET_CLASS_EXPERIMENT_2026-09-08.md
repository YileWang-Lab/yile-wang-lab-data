# V208 single-quadrant asset-class experiment

## Question

Does the V204 post-selection composition exchange erase useful durable
livestock before the first land expansion by replacing it with a one-cycle
crop?

## Runtime rule

V208 retains V204's proposal, crew, route, cash-flow, market-response, land
challenger and turnover programs. The only change is a public-state gate:

- while exactly one quadrant is unlocked, an animal position may exchange
  only with another animal and a crop position only with another crop;
- after another quadrant is unlocked, V204's unrestricted candidate set is
  restored;
- every permitted exchange still needs the existing strict feasible robust
  value improvement certificate.

The asset classes come from the public engine tables. Runtime does not read a
replay, opponent identity, episode key, fitted date, coordinate, quantity or
recorded action.

## Isolation

The production baseline remains V204. V208 is an experiment wrapper and does
not enable V207's land-frontier repair. Promotion requires paired arena
evidence against V204 in addition to unit and runtime-audit success.

## Screen result

Against V204 on the three-opponent hard pool (6 seeds per opponent), V208
fired in all 18 paired cells and produced **-$8,752 per paired cell** with
`A>B = 33.3%`. It is rejected and is not a production candidate. The whole
first-quadrant restriction is too broad.
