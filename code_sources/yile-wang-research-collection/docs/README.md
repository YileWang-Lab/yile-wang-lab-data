# 王毅乐 · 个人论文集

**Yile Wang Research Collection**

![王毅乐个人论文集](assets/cover.png)

这是一部围绕经济发展、数字化转型与可持续治理展开的个人研究典藏。论文集以“发展如何被测量、预测与解释”为主线，将综合评价、空间统计、因果推断、机器学习和数学建模连接起来。

## 研究主题

| 主题 | 主要问题 | 代表方法 |
| --- | --- | --- |
| 发展轨迹 | 如何构建多维现代化指数并识别发展阶段？ | PCA、NAR、Stacking、组合赋权 |
| 金融市场 | 投资者情绪如何影响 IPO 定价效率？ | DML、GRF、PCA 情绪指数 |
| 国际贸易 | “对等关税”如何影响产业链与宏观经济？ | Armington、结构引力、网络流、投入产出 |
| 数字与绿色转型 | 数字经济能否改善绿色绩效并控制碳排放？ | SBM–DEA、GML、空间杜宾、耦合协调 |
| 区域治理 | 区域韧性如何演变，哪些因素最重要？ | Spearman–CRITIC、XGBoost–CatBoost、SHAP |

## 本论文集包含什么

- 6 篇完整论文与 117 页左右的原始研究材料；
- 每篇论文的中文导读、方法框架、核心发现与关键词；
- 可下载的 PDF 或 Word 原文，完整保留公式、图片、表格和参考文献；
- 按论文与章节组织的 GitBook 目录。

> **阅读提示**：论文原文是本论文集的权威版本。网页导读用于快速理解研究问题、方法与结论，不替代原论文中的完整论证。

从[关于作者](about.md)了解研究方向，或直接进入[论文目录](SUMMARY.md)。
