# 原文、公式与图表说明

## 双层内容结构

论文集采用“GitBook 导读 + 原始论文附件”的双层结构：

- **GitBook 导读**负责呈现研究问题、数据范围、方法体系、核心发现与章节索引；
- **原始附件**负责精确保留论文排版、数学公式、图片、统计表格、脚注和参考文献。

## 文件格式

| 格式 | 阅读方式 | 保真范围 |
| --- | --- | --- |
| PDF | 浏览器直接打开或下载 | 矢量文字、公式、图片、表格与页码完整保留 |
| DOCX | 下载后使用 Word/WPS 打开 | Office 公式、图片、表格、页眉页脚与批注结构完整保留 |

## 引用建议

引用时请以原文标题、作者、发表年份和期刊/赛事信息为准。工作论文或未正式出版的研究，建议标注为“工作论文”并注明访问日期。
