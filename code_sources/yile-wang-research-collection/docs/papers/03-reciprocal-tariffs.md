## 研究设计

论文把关税政策拆解为五个相互关联的问题：农产品贸易转移、汽车跨国生产选择、半导体供应链安全、关税财政收入，以及制造业回流的宏观效果。不同模块分别建模，同时通过价格、需求、投入产出和投资渠道连接。

## 五个模型模块

### 1. 大豆贸易

Armington 需求模型刻画中国对不同来源大豆的不完全替代，结构引力模型描述关税引起的贸易转移，供给响应方程模拟巴西、阿根廷和美国的扩产及价格调整。

### 2. 汽车产业

多生产地成本最小化模型比较日本、墨西哥和美国的生产路径，嵌套 Logit 估计消费者在品牌和车型之间的替代，投入产出模块进一步计算美国增加值和就业变化。

### 3. 半导体供应链

多阶段网络流模型覆盖晶圆制造、封装测试与下游需求，并加入动态产能演化。模型比较关税、补贴和出口管制组合下的效率—安全权衡。

### 4. 关税收入

以 HS 商品层级构建局部均衡税收模型，并通过结构引力和动态 Laffer 效应修正进口收缩、替代与贸易伙伴反制。

### 5. 制造业回流

多部门动态投入产出模型将贸易冲击传导至农业、制造、服务和金融部门，并构建 Manufacturing Reshoring Index 衡量产能回流。

## 主要结论

- 美国大豆对华出口份额随关税上升显著下降，南美供应商大幅填补缺口。
- 汽车和半导体产能可向美国及盟友转移，但消费者价格、财政成本和供应链集中风险同时上升。
- 关税收入短期增加，随后被进口收缩与报复性措施侵蚀。
- 制造业回流幅度总体有限，GDP 与就业收益不足以抵消价格、投资和外部需求损失。
