## 韧性评价体系

论文将区域韧性划分为四个子系统：

| 子系统 | 代表指标 |
| --- | --- |
| 经济韧性 | 人均 GDP、人均社会消费品零售额、财政自给率、第三产业占比 |
| 社会发展韧性 | 失业率、医院床位、互联网普及率、高校在校生数 |
| 生态环境韧性 | 绿化覆盖、废水和二氧化硫排放强度、环保支出 |
| 基础设施韧性 | 燃气和供水普及率、道路面积、公共交通车辆 |

多数指标不满足正态分布假设，因此研究使用 Spearman 相关系数改造 CRITIC 权重计算，使指标冲突性测度更适合偏态和极端值较多的省级面板数据。

## 时空分析

- 综合指数用于追踪 2007—2024 年各省韧性变化；
- 冷热点分析识别高值与低值的局部空间集聚；
- 核密度估计刻画分布位置、离散程度与多峰特征；
- 替代权重方案用于检验韧性排序和解释结果的稳定性。

## 可解释机器学习

研究将 XGBoost 与 CatBoost 融合，拟合城市化、政府干预、科技与教育投入、开放度、金融与数字发展、民营经济、收入和社会保障等因素与韧性得分之间的非线性关系。SHAP 值用于解释每个变量对模型预测的边际贡献和方向。

## 核心发现

1. 中国省级区域韧性总体呈上升趋势，但省际差异长期存在。
2. 热点主要集中在东部沿海与部分中东部省份；西部和西南部间歇性出现冷点。
3. 收入水平、民营经济活力与城市化率的模型贡献较大。
4. 影响因素的贡献方向和强度存在区域异质性，统一政策难以覆盖不同地区的约束条件。
