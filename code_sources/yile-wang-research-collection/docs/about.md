# 关于作者

## 王毅乐 · Yile Wang

王毅乐的研究兴趣集中在数字经济、绿色发展、区域经济、发展测度和机器学习的经济学应用。论文署名使用英文名 **Yile Wang**。

研究工作强调三个相互连接的层面：

1. **测度**：将抽象的发展、韧性或协调程度转化为可比较的多维指数；
2. **识别**：借助面板计量、空间模型与因果机器学习分析变量之间的作用关系；
3. **预测与解释**：使用集成学习、神经网络与 SHAP 等方法刻画非线性规律，并将模型结果转化为可解释的政策含义。

## 论文集定位

本论文集既保留可以核查和引用的原始论文，也提供面向一般读者的中文导读。它不是简单的文件下载页，而是一条可以连续阅读的研究脉络：从中国现代化轨迹的综合测度，延伸到数字化与绿色转型，再进入资本市场、国际贸易和区域治理中的具体问题。
