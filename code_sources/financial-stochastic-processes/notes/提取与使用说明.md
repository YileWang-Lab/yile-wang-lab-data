## 二、题目是怎么转出来的

课件中的中文题干可以直接从 PPT 的 XML 里读到，但**公式几乎全部是旧版 Equation 3.0 的 OLE 对象**，
在 XML 中只留下空白占位，在别的软件里也常常无法复制。因此转录分两条线做：

1. 把每份 `.ppt` 转成 `.pptx` 后解包，从 `ppt/slides/slideN.xml` 中提取中文题干；
2. 把每一页幻灯片**渲染成图片**，人工逐页核对公式，再写成 LaTeX。

渲染出来的图片按章节存放在 [`slides/images/`](../slides/images)，
文件名 `slideNN.png` 与课件页码一一对应，并在每道题的解答里以折叠块的形式给出。
图片经过等比缩放（宽 1600px）与调色板压缩，文字与公式仍然清晰，整套只有约 3 MB。

**因此：Markdown 中的公式是对题面的可搜索转写，不会改变原始 PPT；有疑问时以截图或 `.ppt` 为准。**

## 四、阅读建议

- 想自己先做：只看 [`slides/images/`](../slides/images) 里的截图，题面完整。
- 想对答案：打开 `solutions/` 里对应章节，每题都是先**题目**后**解答**。
- 想快速扫结论：看 [README](../README.md) 逐题索引里的「答案要点」一列。
- 课件个别题目只给出符号参数，解答保留一般形式，不擅自补入数值。

## 五、已知问题与勘误

- **第三章第 2 题（书亭订阅收入）**：题面「每订阅 1 年，店主即获利 5 元」是**按年**计费。
  早期版本按「只有订阅 1 年的顾客带来 5 元」计算，得 $E[Y(t)]=15t$、 $D[Y(t)]=75t$；
  正确的复合泊松结果是 $E[Y(t)]=50t$、 $D[Y(t)]=500t$。已订正。
- **第三章第 14 题（移民人口）**：早期版本写 $E(H)=7/3$、 $E(H^2)=8$，
  按题面四个概率 $\frac16,\frac13,\frac13,\frac16$ 加权应为 $E(H)=\frac52$、 $E(H^2)=\frac{43}{6}$，
  故 $E(S)=25$、 $D(S)=\frac{215}{3}$。已订正。
- **第四章第 13 题（比赛得分链）**：「再赛两局可以结束」有两种理解——
  「至迟两局结束」得 $p(1+r)$，「恰在第二局结束」得 $rp$。解答同时注明，以任课教师口径为准。
- 早期版本的 Markdown 里行内公式丢失了 `$` 定界符（形如 `(X\)`、`qquad`），在 GitHub 上无法渲染。
  现已全部改写为标准 `$...$` / `$$...$$`。

## 六、数值结论的复核

所有涉及具体数字的结论（矩阵幂、平稳分布、期望与方差、概率值）都用 SymPy 以精确有理数复核过，
包括第四章第 5、6、9 题的矩阵计算和第三章的各项期望／方差。
若发现仍有出入，请以课堂讲评为准，并欢迎提 Issue 指出。
